# Домашнее задание 2

## Описание

Реализация Gradient Boosting с нуля и практика с CatBoost/XGBoost/LightGBM.

## Структура выполнения

1. Заполните все классы и функции в `homework.ipynb`
2. Инструкция как выполнить домашку и запушить в гитхаб в `hw0/README.md`
3. Проверьте, что решение проходит тесты: `uv run python -m unittest tests/*.py`
4. Запустите ячейки проверки в ноутбуке и убедитесь, что графики выглядят адекватно
